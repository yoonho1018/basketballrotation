NBA 공개 Player Tracking과 Box Score 평균값을 입력하면, 선수별 체력 추정치와 경기 기여도를 계산한 뒤 포지션·피로·목표 출전시간을 동시에 만족하는 48분 로테이션을 백트래킹으로 탐색합니다.

중요한 전제 공개 Tracking 데이터는 VO2max·심박수·혈중 젖산 같은 생리학적 체력 측정값이 아닙니다. 이 프로그램의 “체력”은 평균 출전시간과 이동 강도로부터 가정한 추정치(Endurance/Workload Proxy)입니다.

데이터 일관성 검사

2.5절

    계산된 선수 지표

    3절 · 4절

    WorkRate = DIST_MILES / TRACK_MIN StaminaProxy = 100 × [ α·Norm(TRACK_MIN) + (1−α)·Norm(WorkRate) ] GmSc = PTS +0.4·FGM −0.7·FGA −0.4·(FTA−FTM) +0.7·ORB +0.3·DRB +STL +0.7·AST +0.7·BLK −0.4·PF −TOV GmSc36 = GmSc / BOX_MIN × 36 TargetMin = 240 × BOX_MIN / Σ BOX_MIN

    아래 값들은 생리학적 상수가 아니라 시뮬레이션 파라미터입니다. 값을 바꿔가며 로테이션이 어떻게 달라지는지 비교하는 것이 이 프로그램의 핵심 탐구입니다.

    체력 추정 · 피로 모델

    3절

    PlayIncrease = BASE × (0.8 + 0.4·WorkNorm) × (1.2 − 0.4·StaminaNorm) 출전 1분 : Fatigue ← min(100, Fatigue + PlayIncrease) 벤치/휴식 : Fatigue ← Fatigue × exp(−λ × rest_minutes)

    라인업 · 교체 제약조건

    5절 · 하드 제약

    하드 제약을 위반한 라인업은 점수를 깎는 것이 아니라 후보에서 즉시 제거됩니다. 최대 로테이션 인원을 로스터보다 작게 설정하면, 알고리즘이 BOX_MIN·Quality·포지션 커버를 바탕으로 먼저 Rotation Pool을 구성하고 그 밖의 선수는 탐색 후보에서 제외합니다.
    최대 총 교체 횟수는 경기 중 라인업이 이전 분과 달라지는 시점을 세는 상한입니다. 같은 시점에 2~5명이 함께 바뀌어도 경기 흐름이 끊기는 시점은 하나이므로 교체 이벤트 1회로 계산합니다.
    역할 매핑: PG → Guard·Handler / SG → Guard·Wing / SF → Wing / PF → Wing·Big / C → Big. 복수 포지션은 PF/C처럼 표기합니다.

    목적함수 가중치

    7절

    TotalCost = wF·FatigueCost + wM·MinuteCost + wQ·QualityCost + wS·SubCost FatigueCost += mean( fatigue² / 10000 ) · MinuteCost = Σ |played_min − TargetMin| QualityCost += max(0, QualityThreshold − LineupQuality)² / 10000 · SubCost += 교체 인원 Hard constraint: Σ 1(Lineupₜ ≠ Lineupₜ₋₁) ≤ 최대 총 교체 횟수

    지원 형식과 데이터 구하는 법

    A. NBA Stats gamerotation — 공식 엔드포인트가 주는 형식 그대로입니다. 가장 정확합니다.

    PLAYER_FIRST,PLAYER_LAST,IN_TIME_REAL,OUT_TIME_REAL Stephen,Curry,0,4680 Klay,Thompson,0,4650

    IN/OUT은 경기 시작부터의 경과시간을 1/10초 단위로 센 값입니다(48분 = 28800). Python에서 nba_api의 GameRotation, R에서는 hoopR::nba_gamerotation()으로 받은 표를 CSV로 저장해 그대로 넣으세요.

    B. 스틴트 (게임 시계) — Basketball-Reference의 play-by-play를 손으로 옮길 때 편한 형식입니다.

    player,quarter,in,out Stephen Curry,1,12:00,4:15 Stephen Curry,2,7:46,0:00

    쿼터별로 12:00에서 0:00으로 내려가는 게임 시계를 씁니다. 한 선수가 여러 줄을 가져도 됩니다.

    C. 스틴트 (경과 분) — 0~48분 경과시간으로 직접 적는 방식입니다.

    player,start_min,end_min Stephen Curry,0,7.75 Stephen Curry,16.2,24

    어느 형식이든 선수 이름은 로스터와 자동으로 맞춥니다(성만 같아도 인식). 데이터가 아예 없으면 아래 표를 직접 칠하세요.

    직접 칠하기
